# AI Workout / Virtual PT — name shortlist

Working doc. Updated as we test more candidates with `scripts/check-name.mjs`.

## Top picks so far

Filter: no App Store exact match, no Play Store exact-name hit, ≥4 preferred TLDs
free (`.app .io .ai .co`). GitHub handle availability is ignored as a weak signal.

1. **Trainara** — 🟢 fully unclaimed across stores, domains, handles.
   Pronounceable but slightly invented. Trademark unverified.
2. **Coachsmith** — clean stores, `.app .io .ai .co .fit .fitness .coach` all free.
   Strong brand connotation ("smith" = craft).
3. **Sterkr** — Old Norse "stronger". Norwegian flavor, distinct internationally.
   `.io .co .fit .fitness .coach .ai` free.
4. **Bodewise** — clean stores, mature/wellness tone.
5. **Tryner** — clean stores, phonetic "trainer". `.com` taken.
6. **Fitchain** — clean App Store, Play fuzzy only. "chain" reads crypto-adjacent.
7. **Athlon** — clean stores but Decathlon/AMD Athlon associations.
8. **Repify** — clean stores, generic `-ify` pattern.
9. **Hone** — clean stores, but likely trademark-heavy in fitness.
10. **Mentr** — clean stores, close to existing "Mentor" apps.
11. **Kineta** — clean stores, but Kineta Inc. (pharma) is a trademark risk.
